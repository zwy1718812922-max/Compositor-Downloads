## 下载安装

**[下载 Windows 完整安装包 · 0.11.0](https://github.com/zwy1718812922-max/Compositor-Downloads/releases/latest/download/Compositor-ZH-0.11.0-x64-Setup.exe)**

- 系统：Windows 11，64 位（x64）。
- 下载 EXE 后双击，按照中文安装向导选择目录并完成安装。
- 完整安装包包含 Electron 和浏览器运行环境，无需安装 Node.js、npm 或 WebView2。
- 更新前请保存作品并关闭正在运行的 Compositor。

## 功能与项目文件

支持图层、蒙版、文字、形状、渐变、PSD 导入导出，以及本地 AI 图像处理。0.11.0 默认保存为 `.ccompx`，可读取旧版 `.ccomp`，并支持检查点恢复。
